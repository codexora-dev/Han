# 1. 개요

Han Language Keyword는 Han 프로그래밍 언어에서 사용하는 예약어(Keyword)를 정의하는 공식 문서입니다.

예약어는 언어에서 특별한 의미를 가지는 단어이며, 변수면, 함수명, 클래스명 등 일반 식별자로 사용할 수 없습니다.

본 문서는 예약어의 목적과 의미를 정의하며, 세부 문법은 Han Language Grammar 문서를 따릅니다.

---

# 2. 예약어 설계 원칙

Han의 예약어는 다음 원칙을 기반으로 설계됩니다.

- 한국어 사용자에게 자연스럽게 읽혀야 합니다.
- 의미가 명확해야 합니다.
- 하나의 예약어는 하나의 기능만 수행해야 합니다.
- 불필요한 예약어 추가를 지양합니다.
- 언어의 일관성을 유지합니다.

---

# 3. 예약어 분류

Han의 예약어는 다음과 같이 분류됩니다.

- 입출력
- 변수 및 상수
- 자료형
- 조건문
- 반복문
- 함수
- 객체 지향
- 예외 처리
- 모듈
- 기타

# 5. 예약어 사용 규칙

예약어는 언어에서 특별한 의미를 가지므로 식별자로 사용할 수 없습니다.

다음은 허용되지 않는 예입니다.

```
변수 출력 = 100
```

위 예시는 `출력`이 예약어인 경우 오류가 발생합니다.

---

# 6. 예약어 추가 정책

새로운 예약어는 다음 기준을 만족해야 합니다.

- 기존 예약어와 의미가 중복되지 않을 것
- 한국어 사용자에게 직관적일 것
- 문법의 일관성을 유지할 것
- 장기적인 유지보수가 가능할 것

---

# 7. 예약어 변경 정책

이미 공개된 예약어는 가능한 변경하지 않습니다.

예약어 변경이 필요한 경우에는 다음 사항을 검토합니다.

- 기존 코드와의 호환성
- 사용자 영향
- 언어 철학과의 일치 여부
