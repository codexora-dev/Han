# 1. 개요

Han Language Grammar는 Han 프로그래밍 언어 문법(Syntax)을 정의하는 공식 문서입니다.

본 문서는 Han 소스 코드가 어떤 형식으로 작성되어야 하는지 정의하며, 컴파일러와 개발 도구는 본 문서를 기준으로 구현됩니다.

문법은 언어의 발전에 따라 변경될 수 있으며, 모든 변경 사항은 관련 설계 문서를 통해 관리됩니다.

---

# 2. 문법 설계 원칙

Han의 문법은 다음 원칙을 기반으로 설계됩니다.

- 한국어 사용자에게 자연스러운 표현을 사용한다.
- 사람이 읽기 쉬운 코드를 우선한다.
- 하나의 기능은 하나의 표현 방식을 원칙으로 한다.
- 불필요한 기호와 복잡성을 최소화한다.
- 일관된 문법을 유지한다.

---

# 3. 문자 집합

Han은 UTF-8 문자 인코딩을 기본으로 합니다.

소스 코드에는 다음 문자를 사용할 수 있습니다.

- 한글
- 영어
- 숫자
- 공백 문자
- 지정된 특수문자

---

# 4. 식별자(Identifier)

식발자는 변수, 함수 클래스, 모듈 등의 이름을 나타냅니다.

## 설계 원칙

- 의미를 쉽게 이해할 수 있는 이름을 권장합니다.
- 한글과 영문 사용을 지원합니다.
- 숫자로 시작하는 이름은 허용하지 않습니다.
- 예약어는 식별자로 사용할 수 없습니다.

예시(예정)

```
이름
학생수
total
userName
```

# 8. 명령문(Statement)

Han 프로그램은 하나 이상의 명령문으로 구성됩니다.

명령문의 종류는 다음과 같습니다.

- 변수 선언
- 값 대입
- 함수 호출
- 조건문
- 반복문
- 반환문

각 명령문의 문법은 별도 절에서 정의합니다.
