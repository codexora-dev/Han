# Han

## 한국인을 위한 현대적인 프로그래밍 언어

Han(한)은 한국어를 기반으로 설계되는 오픈소스 프로그래밍 언어 프로젝트입니다.

기존의 많은 프로그래밍 언어는 영어 키워드와 영어 중심의 개발 환경으로 만들어졌습니다.
Han은 프로그래밍을 배우고 사용하는 과정에서 언어적 장벽을 낮추고, 한국어 사용자가 자신의 생각을 더욱 자연스럽게 코드로 표현할 수 있는 환경을 만드는 것을 목표로 합니다.

---

## 프로젝트 개요

Han은 단순히 기존 프로그래밍 언어의 키워드를 한글로 번역하는 프로젝트가 아닙니다.

프로그래밍 언어의 구조와 사용 경험을 한국어 환경에 맞게 설계하여, 초보자부터 개발자까지 사용할 수 있는 현대적인 프로그래밍 언어를 만드는 것을 목표로 합니다.

Han은 다음과 같은 방향성을 가지고 개발됩니다.

- 한국어 기반의 직관적인 문법
- 프로그래밍 입문자의 학습 부담 감소
- 읽기 쉬운 코드 작성 환경
- 현대적인 프로그래밍 언어 기능 지원
- 개방적인 개발 생태계 구축

---

## 개발 목표

Han은 다음과 같은 목표를 가지고 있습니다.

### 한국어 기반 개발 환경

프로그래밍의 핵심 개념을 영어 문법을 해석하는 과정 없이 이해할 수 있도록 한국어 중심의 언어 환경을 제공합니다.

### 교육 친화적인 언어

처음 프로그래밍을 접하는 사용자가 변수, 조건문, 반복문, 함수 등의 개념을 자연스럽게 학습할 수 있도록 설계합니다.

### 현대적인 프로그래밍 언어

단순한 교육용 언어가 아닌, 실제 개발 환경에서 활용할 수 잇는 기능과 구조를 갖춘 언어를 목표로 합니다.

### 개방적인 생태계

오픈소스 프로젝트로 개발하여 누구나 연구하고 개선할 수 있는 환경을 만드는 것을 목표로 합니다.
