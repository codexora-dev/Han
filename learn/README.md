# Han 배우기

`Han IDE`의 `Han 배우기` 기능에서 사용하는 학습 자료입니다.

## 학습 순서

1. `01_hello.han`: 출력과 파일 구조
2. `02_variables_and_math.han`: 변수와 산술 연산
3. `03_input_greeting.han`: 입력과 문자열
4. `04_condition.han`: 조건문과 비교
5. `05_repeat.han`: 반복문
6. `06_function.han`: 함수와 매개변수
7. `07_logic_and_comparison.han`: 논리 연산
8. `08_menu_program.han`: 여러 문법의 조합

## IDE에서 사용하기

1. `IDE/app.py`를 실행합니다.
2. 상단의 `Han 배우기`를 선택합니다.
3. 단원을 읽고 `예제를 편집기로 열기`를 누릅니다.
4. 편집기에서 F5를 눌러 실행합니다.

입력 예제는 새 터미널이 열리면 안내된 값을 입력합니다. 모든 예제는 프로젝트의 현재 lexer, parser, code generator가 지원하는 문법을 기준으로 작성되어 있습니다.
