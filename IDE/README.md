# Han IDE

Han 언어를 편집하고 실행하기 위한 Python 기반 IDE입니다.

## 실행

```powershell
cd C:\Users\PC\Desktop\IDE
python app.py
```

또는 `run.bat`을 더블클릭하세요.

## 주요 기능

- 파일 탐색기: Han 프로젝트 폴더의 파일을 더블클릭해서 열기
- 편집기: 탭 편집, 저장, 다른 이름 저장, 찾기
- 문법 강조: 예약어, 문자열, 숫자, 주석, 연산자 색상 표시
- 콘솔: 현재 `.han` 파일 컴파일 및 실행 결과 확인
- 입력 실행: `입력` 문이 있는 프로그램에 테스트 입력 전달
- 설정: 테마, 글꼴, 글자 크기, 줄 번호, 자동 줄바꿈, Han 프로젝트 경로 변경

## 단축키

- `Ctrl+N`: 새 파일
- `Ctrl+O`: 파일 열기
- `Ctrl+S`: 저장
- `Ctrl+Shift+S`: 다른 이름으로 저장
- `Ctrl+F`: 찾기
- `F6`: 컴파일
- `F5`: 실행

## 참고

기본 Han 프로젝트 경로는 `C:\Users\PC\Desktop\Han`입니다. 다른 위치에 있다면 IDE의 `보기 > 설정`에서 Han 폴더를 바꾸면 됩니다.
